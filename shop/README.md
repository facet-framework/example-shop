# Shop

A small TypeScript shop: discount codes, orders, refunds and invoices. See the
[repository README](../README.md) for what this example is and is not.

```sh
cd shop
npm test    # tests
npm start   # serves the shop on port 3000
```

Tests and server run with Node.js 22.18 or later, without a build step.
